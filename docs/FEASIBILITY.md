# Keputusan backlog Woof Cleaner

R01 sampai R05 merupakan riset desain per 25 November 2026. Estimasi di bawah adalah hari kerja satu pengembang untuk prototipe dan pengujian awal. Urutan setelah 1.0 masih usulan.

| Batch | Keputusan | Perkiraan dan hasil yang perlu diuji |
|---|---|---|
| R01 · Tray | Layak sebagai opsi. Minimize tetap menuju taskbar secara default. Bila pengguna mengaktifkan tray, menu menyediakan Buka dan Keluar. Keluar saat Clean berjalan menunggu pembatalan selesai. | 2–3 hari. Uji klik, keyboard, restart Explorer, restore jendela, dan keluar saat idle atau sibuk. [Windows notification area](https://learn.microsoft.com/en-us/windows/win32/shell/notification-area) |
| R01 · Bahasa | Mulai dengan Bahasa Indonesia dan katalog gettext stdlib. Audit AST menemukan 163 argumen UI berupa literal atau f-string pada atribut `text`, `label`, dan `tree_heading`. Dialog, heading posisional, pesan worker, kolom, dan plural masuk inventaris tambahan. | 3–5 hari untuk satu alur lengkap. Dua label panjang di Custom Clean masuk pada lebar 904 piksel dengan Tk 150%, termasuk setelah maximize dan restore. Usulan 1.1 bersama tray. |
| R02 · Diagnostik dan rollback | Mulai dari wizard baca-saja. Gunakan device ID, versi driver, dan problem code yang sudah dibaca Driver Updater. Misalnya, kode 43 berarti perangkat melaporkan masalah. Periksa ketersediaan backup driver sebelum menawarkan rollback melalui Windows. | 2–3 hari untuk diagnostik, 4–6 hari untuk prototipe rollback. Uji pada perangkat cadangan dengan dua versi driver, catat versi awal, upgrade, rollback, reboot bila diminta, dan verifikasi perangkat kembali berfungsi. Ulangi dengan backup kosong dan akun biasa. Usulan setelah 1.0. [Kode Device Manager](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/device-manager-error-messages) dan [DiRollbackDriver](https://learn.microsoft.com/en-us/windows/win32/api/newdev/nf-newdev-dirollbackdriver) |
| R03 · Storage | Mulai dari inventaris alternate data streams pada NTFS. Tunda penghapusan permanen, wipe ruang kosong, serta recovery sampai ada image uji dan definisi keberhasilan per filesystem. Operasi wipe Windows mencakup ruang bebas satu volume. Recovery memerlukan tujuan penyimpanan terpisah. | 3–5 hari untuk eksperimen pada salinan VHD NTFS dan exFAT. Tanam file dengan hash diketahui, tambah stream pada NTFS, hapus fixture, dan ukur hasil pembacaan stream, recovery, serta dampak wipe pada salinan terpisah. Catat batas pengamatan untuk SSD/TRIM. [File streams](https://learn.microsoft.com/en-us/windows/win32/fileio/file-streams), [cipher](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/cipher), [Windows File Recovery](https://support.microsoft.com/en-us/windows/experience/backup-recovery/windows-file-recovery) |
| R04 · Temporary uninstall | Uji pemulihan satu aplikasi portabel dahulu. Manifest mencatat file, hash, hak akses, konfigurasi pengguna, registry, dan masa retensi yang dipilih. Uninstaller vendor dapat mengubah layanan, dependensi bersama, atau data di luar folder aplikasi. | 4–6 hari. Ambil snapshot di VM, hapus aplikasi fixture, pulihkan, lalu bandingkan hash, registry, dan hasil peluncuran. Tunda janji restore aplikasi MSI sampai skenario dependensinya lulus. [VSS](https://learn.microsoft.com/en-us/windows/win32/vss/volume-shadow-copy-service-overview) |
| R04 · Sleep mode | Batasi prototipe pada aplikasi pengguna yang memiliki mekanisme keluar dan mulai kembali. Simpan status awal agar Wake dapat memulihkan pilihan. Keluarkan layanan sistem kritis dari kandidat. | 3–5 hari. Pakai dua aplikasi fixture yang berbagi resource, uji pekerjaan belum tersimpan, aplikasi sudah tutup, dan pemanggilan Wake dua kali. Prioritas sesudah diagnostik. [Restart Manager](https://learn.microsoft.com/en-us/windows/win32/rstmgr/critical-system-services) |
| R05 · Cloud | Mulai dari inventaris dan estimasi pada satu akun uji per provider. Google Drive dapat membatasi akses ke file terpilih melalui `drive.file`. OneDrive memakai izin delegasi `Files.ReadWrite` untuk memindahkan item ke Recycle Bin. Dropbox membedakan App Folder/Full Dropbox dan scope baca/tulis. Untuk file bersama, periksa pemilik dan hak tindakan sebelum menghitung kandidat. | 3–5 hari **per provider**, di luar waktu persetujuan aplikasi OAuth. Catat ukuran metadata, kuota sebelum/sesudah, serta status Trash dan restore. Tunda penghapusan permanen. Uji retensi dan pencabutan token pada akun uji. [Google scopes](https://developers.google.com/workspace/drive/api/guides/api-specific-auth), [Google Trash](https://developers.google.com/workspace/drive/api/guides/delete), [Microsoft Graph](https://learn.microsoft.com/en-us/graph/api/driveitem-delete?view=graph-rest-1.0), [Dropbox OAuth](https://developers.dropbox.com/oauth-guide), [Dropbox restore](https://help.dropbox.com/delete-restore/recover-deleted-files-folders) |
| R05 · Informasi sistem | Layak sebagai tampilan baca-saja. Contoh aktual dari akun standar di PC uji adalah Microsoft Windows 11 Pro Education, 64-bit, build 26300. Tiga kolom itu cukup untuk laporan dukungan awal. | 1–2 hari. Tambahkan ke Settings sesudah 1.0, lalu uji ketika CIM tidak tersedia. [Win32_OperatingSystem](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-operatingsystem) |
